# Trading Card Collection Single Page Web App

A single page web application for allowing users to create accounts and store a record of their collection of Magic the Gathering cards

## Built with
HTML, CSS, JS

## Intended Features*
- Sign up or login/logout account support
- Add cards by name
- Accesses an API to fetch details on the cards
- Displays a list of the cards in a table below

*The original API may be missing, as it was a 3rd party one, also the code does seem to be missing the part that actually uses the API
